About the studio

Every game has a main mode.

The one people return to once the novelty wears off. That is the only mode worth building, so it is the one we start from.

Main Mode Studio is an independent studio making original apps and games. Everything begins as a system on paper—rules, numbers, trade-offs—and only becomes a screen once the system is genuinely worth playing. That keeps the catalog small on purpose: a release goes out when it still holds up on the tenth run, not the first.
