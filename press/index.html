The studio

Main Mode Studio is a one-person studio: one designer-developer writing the systems, the code and the balance numbers. It makes games about systems you can practise—money, risk and the trade-offs that decide how things go—short enough to finish in a sitting. One game at a time, free, with nothing that matters behind a paywall.
